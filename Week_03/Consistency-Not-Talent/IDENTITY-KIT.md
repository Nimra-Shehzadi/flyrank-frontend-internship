# Portfolio Identity Kit

## 1. Brand Direction

### Overall Style
Clean, modern, professional, and technology-focused.

The visual identity should frame the work rather than compete with it. The portfolio should feel consistent across pages, projects, and supporting visuals.

### Visual Mood
- Modern
- Minimal
- Professional
- Confident
- Developer-focused
- Clean and approachable

---

## 2. Typography

### Primary Font
Inter

### Usage
- Large headings: Bold / Semi-Bold
- Section headings: Semi-Bold
- Body text: Regular
- Buttons and labels: Medium / Semi-Bold

Typography should remain consistent across the entire portfolio.

---

## 3. Color Palette

### Primary
#0F5132

Used for:
- Main headings
- Primary buttons
- Important accents

### Text
#10231A

Used for:
- Body text
- Navigation
- Secondary headings

### Background
#F7FAF8

Used for:
- Main page background
- Content sections

### Accent
#54E399

Used for:
- Highlights
- Hover states
- Small visual accents
- Interactive elements

---

## 4. Color Usage Rule

The portfolio should use a limited color palette.

Primary green should establish the visual identity while the accent green should be used sparingly for emphasis.

Avoid unnecessary colors, excessive gradients, and visually competing effects.

---

## 5. Logo Direction

### Logo Concept

Use a minimal personal developer mark based on the initials:

NS

The logo should be:
- Simple
- Readable
- Professional
- Easy to recognize at small sizes

It should work on both light and dark backgrounds.

---

## 6. Favicon Direction

The favicon should use the same NS personal mark as the main logo.

This keeps the browser identity consistent with the portfolio branding.

---

## 7. UI Style

### Buttons
- Rounded corners
- Clear labels
- Strong hover feedback
- Consistent spacing

### Cards
- Soft rounded corners
- Subtle borders
- Light shadows
- Clean spacing

### Sections
- Generous whitespace
- Clear visual hierarchy
- Consistent section spacing

---

## 8. Animation Direction

Animations should support usability rather than distract from the projects.

Preferred:
- Smooth hover transitions
- Subtle entrance animations
- Soft scrolling effects
- Gentle card movement
- Smooth CTA interactions

Avoid:
- Excessive animations
- Flashing effects
- Heavy particle effects
- Distracting 3D elements

---

## 9. Image Direction

Real screenshots should be prioritized for project presentation.

AI-generated images may be used only when they support the visual identity or connect sections without replacing evidence of actual work.

---

## 10. Consistency Rules

The same:
- Font family
- Color palette
- Button style
- Border radius
- Spacing system
- Animation style
- Image treatment

should be maintained throughout the portfolio.

---

## Design Principle

The portfolio design should act as a frame for the work, not an upgrade that tries to overpower it.
