# Portfolio Image Curation

## Goal

Use visuals that support the portfolio's credibility and clearly show real work.

## Selected Visuals

### 1. Professional Profile Image
Purpose:
- Personal identity
- Hero/about section
- Professional introduction

Selection criteria:
- Clear face
- Good lighting
- Clean background
- Professional appearance
- Consistent with portfolio color direction

### 2. NutriVision AI
Use:
- Real project screenshot
- AI food recognition interface
- Prediction / nutrition result

Purpose:
- Demonstrate AI/ML development
- Provide visual proof of the project

### 3. PetHub
Use:
- Real homepage screenshot
- Adoption / pet-care interface

Purpose:
- Demonstrate frontend and full-stack development

### 4. Watch Luxora
Use:
- Real website screenshot
- Product / watch interface

Purpose:
- Demonstrate UI design and frontend implementation

### 5. FlyRank Internship
Use:
- Relevant project screenshots
- Internship completion evidence
- Selected weekly project work

Purpose:
- Demonstrate practical development experience

---

## Image Selection Rules

### Keep
- Real project screenshots
- Clear professional images
- High-resolution visuals
- Images that communicate the project's purpose quickly
- Consistent aspect ratios where possible

### Reject
- Blurry screenshots
- Duplicate screenshots
- Random stock images
- Unrelated AI-generated visuals
- Images that do not support the project
- Overly decorative graphics

---

## Image Treatment

Project images should use:

- Consistent rounded corners
- Clean framing
- Subtle shadows
- Appropriate cropping
- Consistent aspect ratios

Avoid excessive filters or effects that change the appearance of the actual project.

---

## AI Image Rule

AI-generated images should only be used when they add useful visual context.

They should never replace screenshots or other evidence of real project work.

The final portfolio should prioritize authenticity over decoration.

---

## Final Selection Principle

Every image should answer at least one question:

1. What did I build?
2. What technology did I use?
3. What problem does it solve?
4. What does the final product look like?
5. What experience does this demonstrate?

If an image does not help answer one of these questions, it should not be included.
