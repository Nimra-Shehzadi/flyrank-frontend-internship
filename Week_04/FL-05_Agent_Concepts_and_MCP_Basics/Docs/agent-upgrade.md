# How My Workflow Could Become an Agent

Currently, my FL-04 project is a workflow because it follows a fixed sequence of predefined steps.

To transform it into an AI agent, it would need additional capabilities:

- Automatically search for project information.
- Decide which prompts to use based on the project type.
- Access external files through MCP.
- Generate documentation without manual intervention.
- Review outputs automatically before publishing.
- Adapt its behavior when information is incomplete.

With these capabilities, the system would make decisions independently rather than simply following predefined instructions.
