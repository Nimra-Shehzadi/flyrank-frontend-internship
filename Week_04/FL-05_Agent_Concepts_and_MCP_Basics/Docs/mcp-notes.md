# MCP Basics

## What is MCP?

Model Context Protocol (MCP) is an open standard that allows AI applications to communicate with external tools, services, and data sources using a common interface.

## Three Core Primitives

### 1. Tools

Tools allow an AI model to perform actions such as searching files, running code, or calling APIs.

### 2. Resources

Resources provide external information that the AI can read, including documents, databases, and local files.

### 3. Prompts

Prompts define reusable instructions that guide the AI in completing tasks consistently.

## Why MCP Matters

MCP enables AI assistants to interact with real-world systems instead of relying only on conversation. It makes AI applications more powerful, flexible, and capable of completing practical tasks.
