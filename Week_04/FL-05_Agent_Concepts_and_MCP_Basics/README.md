# Agent Concepts and MCP Basics (FL-05)

## Overview

This project was completed as part of the FlyRank Frontend AI Engineering Internship (Week 4).

The assignment explores the difference between AI workflows and AI agents while introducing the fundamentals of the Model Context Protocol (MCP).

---

## Objectives

- Understand the difference between workflows and AI agents.
- Learn the basics of MCP.
- Demonstrate AI-assisted task execution.
- Explain how an automation workflow can evolve into an AI agent.
