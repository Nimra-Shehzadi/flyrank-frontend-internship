# Gap Between World & App

A React + Vite frontend application demonstrating real-world UI states that every production AI application should handle.

---

## Objective

This project demonstrates the difference between an ideal AI response and real-world product behavior by handling different UI states.

---

## Features

- ✅ Success State
- 📭 Empty State
- ⏳ Loading State
- ❌ Error State
- ⚠ Mid-Stream Failure
- 🔄 Retry Button
- Responsive Layout
- Modern Dark UI

---

## Tech Stack

- React
- TypeScript
- Vite
- CSS
