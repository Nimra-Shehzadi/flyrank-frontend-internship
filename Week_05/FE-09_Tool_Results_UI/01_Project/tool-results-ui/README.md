# Tool Results & Structured Output

A frontend project built with React + Vite that demonstrates how structured AI tool responses can be rendered in a clean user interface.

---

## Objective

Display AI-generated structured output instead of plain text while handling different UI states.

---

## Features

- AI Response Card
- Structured JSON Output
- Error State
- Loading State
- Responsive Layout
- Modern Dark UI

---

## Tech Stack

- React
- TypeScript
- Vite
- CSS
