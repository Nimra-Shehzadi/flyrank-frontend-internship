# 🌿 SearchMind AI

SearchMind AI is a simple AI-powered keyword research assistant built with React and TypeScript. It demonstrates how structured AI responses can be displayed in a clean and user-friendly interface.

---

## ✨ Features

- Keyword input
- Simulated AI keyword analysis
- Search intent detection
- SEO score display
- Suggested SEO title
- Optimization recommendations
- Responsive modern UI
- Built with React + TypeScript

---

## 🛠️ Tech Stack

- React
- TypeScript
- CSS3
- Vite
